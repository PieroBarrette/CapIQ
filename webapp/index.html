    Calibration du capteur

    Connectez-vous au casque pour lancer une calibration. À faire au premier montage, puis à chaque changement de position des composants sur la casquette. S'éloigner de tout métal (véhicule, scie).

    Dépannage Bluetooth

    Ne jumelez pas Capiq dans les réglages Bluetooth d'Android. Le casque n'utilise aucun appairage : le jumelage occupe la liaison et empêche l'application de s'y connecter. Si Capiq figure déjà dans la liste des appareils jumelés, choisissez Oublier.

    Connexion toujours impossible ? Dans l'ordre :
    1. désactiver puis réactiver le Bluetooth du téléphone ;
    2. redémarrer le casque (débrancher/rebrancher) ;
    3. utiliser Afficher tous les appareils Bluetooth sur l'écran Guidage si « Capiq » n'apparaît pas dans la liste ;
    4. vérifier qu'aucun autre téléphone n'est déjà connecté au casque.

    Sur Android, si la liste du sélecteur reste vide, c'est presque toujours l'un de ces deux points :
    • la Localisation (GPS) du téléphone est désactivée — Android l'exige pour que Chrome puisse scanner en BLE, même sans usage du GPS ;
    • la permission Appareils à proximité est refusée à Chrome (Paramètres → Applications → Chrome → Autorisations).
